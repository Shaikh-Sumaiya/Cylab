Can you convert the number 42 (base 10) to binary (base 2)?

Solution:

For this lab we will be using the website 'https://gchq.github.io/CyberChef/'

Put the number 42 in the input part of the website
Find the 'To Base' from the Operations part which will be under Data Format

Drag it to the Recipe area of the website, change Radix to '2'

We will get the required number in output

Use this number to submit the flag in the format that is being used till now
academy{number}

In this case, number is 101010, so the flag becomes academy{101010}
