What is 0x3D (base 16) in decimal (base 10)?

Solution:

This lab can be solved from the website 'https://gchq.github.io/CyberChef/'

In this, a base 16 number is given to us and we are asked to convert it into decimal or base 10 number

We will paste this (0x3D) into the input area of the cyberchef website. 
Then we will search 'To Base' which is inside Data Format in the Operations part of the website. We will drag it to the Recipe area and in
Radix type '10'
This will now convert our input into base 10 number

Whatever number we are getting in output we have to submit it as a flag in the lab
Use the previously submitted format which is 'academy{number}'

In this case, 61 so the flag becomes academy{61}
